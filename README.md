# TutorSetu

Har bacche ke liye, sahi tutor.

## Files
All website files are kept in the repository root so they are easy to upload from an Android device.

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.
6. Admin: `http://localhost:3000/admin`

## Default admin for first local run
Username: `admin`
Password: `ChangeMe123!`

Change the password/configuration before production. Set `ADMIN_USERNAME`, `ADMIN_PASSWORD`, and `SESSION_SECRET` as environment variables on the host.
